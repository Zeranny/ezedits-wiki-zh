# 默认调色板

默认情况下，调色板是按玩家个人保存的。然而，服务器管理员可以在以下路径中定义一组供所有玩家访问的默认调色板：

```
plugins/ezEdits/resources/DefaultPalettes.json
```

我们也预置了一系列默认调色板：
