# 超级魔杖

超级魔杖工具提供四种不同的模式用于点选择和操作，提供了一种扩展的区域选择工作方式。

**强烈推荐使用 WorldEditCUI：** [**https://modrinth.com/mod/worldedit-cui**](https://modrinth.com/mod/worldedit-cui)

### 模式

1. <mark style="color:orange;">**追踪模式**</mark>：选择你正在瞄准的方块。
2. <mark style="color:orange;">**位置模式**</mark>：选择你当前玩家位置处的方块。
3. <mark style="color:orange;">**相对模式**</mark>：选择相对于上一个放置的点和玩家瞄准方向的点。
4. <mark style="color:orange;">**抓取模式**</mark>：允许抓取和移动一个点或整个选择区域。

### 控制

* <mark style="color:blue;">**右键点击**</mark>：
  * 在点选择模式中，选择一个新点或在选择区域已满时替换最近的点。
  * 在抓取模式中，拾起一个点或整个选择区域，随玩家的移动而移动。
* <mark style="color:blue;">**左键点击**</mark>：
  * 在点选择模式中，移除最后设置的点。
  * 在抓取模式中，放下该点或选择区域。
* <mark style="color:blue;">**潜行 + 左键点击**</mark>：循环切换工具模式。
* <mark style="color:blue;">**交换手（默认 F 键）**</mark>：反转选择区域中的点的顺序。
* <mark style="color:blue;">**潜行 + 交换手（默认 F 键）**</mark>：将所有凸选择点沿点列表中的位置移动一个位置。
